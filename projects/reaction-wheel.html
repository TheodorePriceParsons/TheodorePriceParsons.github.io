Reaction-Wheel Inverted Pendulum

Balancing a pendulum with a spinning reaction wheel. LQR state feedback with an observer, plus a Python simulation package.

LQRLuenberger observerSTM32F446REPython

How it works

Overview

A long-running solo project: an inverted pendulum kept upright by accelerating a reaction wheel. The controller runs on an STM32F446RE.

Control

  • Full-state feedback designed with LQR.
  • A Luenberger observer estimates the states that aren't measured directly.

Simulation

The simulation is being refactored into a proper Python package with separate sim/ modules, so the controller can be tuned and tested before it touches hardware.
